# Политика безопасности

Не публикуйте сведения об уязвимостях и секреты в открытых issue.

Никогда не добавляйте в репозиторий токены T-Invest API, `.env`, идентификаторы реальных счетов, приватные ключи и чувствительные журналы.

При утечке токена немедленно отзовите его, создайте новый, удалите секрет из текущей версии и истории Git и проверьте операции по счёту.

Проект не проходил независимый аудит безопасности и не предназначен для управления реальными средствами в текущем состоянии.
