# Участие в разработке

1. Создайте issue.
2. Создайте отдельную ветку.
3. Не добавляйте токены, `.env` и отчёты.
4. Сохраняйте модульное разделение проекта.
5. Обновляйте документацию при изменении поведения.
6. Перед pull request выполните:

```bash
python -m compileall .
python main.py --dry-run
```

В pull request опишите изменение, способ проверки, влияние на торговую логику и известные риски.
